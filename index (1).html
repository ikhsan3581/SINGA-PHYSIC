Download & Install SINGA PHYSIC di HP

METODE 1 • PALING MUDAH & BISA DIBUKA OFFLINE

Unduh File Paket Aplikasi Mandiri (SINGA_PHYSIC_Mobile_App.html)

Seluruh 21 Bab Materi, Gambar Rumus, 8 Simulasi Interaktif, dan Latihan Soal dikemas dalam 1 file aplikasi mandiri SINGA PHYSIC. Simpan di memori HP Anda dan buka kapan saja dengan Chrome/Safari.

Cara Pasang di HP Android
  1. Klik tombol Download File SINGA PHYSIC di atas, lalu buka file tersebut di aplikasi Google Chrome HP.
  2. Ketuk ikon titik tiga di pojok kanan atas Chrome.
  3. Pilih menu "Tambahkan ke Layar Utama" (Add to Home Screen) atau "Install Aplikasi".
  4. Ikon SINGA PHYSIC akan muncul di menu HP seperti aplikasi Android asli!
Cara Pasang di iPhone / iOS
  1. Buka file atau halaman aplikasi ini menggunakan browser Safari di iPhone/iPad.
  2. Ketuk tombol Bagikan (Share) di bilah bawah Safari.
  3. Gulir ke bawah lalu pilih "Tambah ke Layar Utama" (Add to Home Screen).
  4. Ketuk Tambah. Aplikasi siap dibuka dalam mode layar penuh tanpa bar browser.
